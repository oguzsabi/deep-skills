# issue-list

A small issue list built as the subject of the [deep-feature example](../README.md). It's a real app with real tests: the flow ran against it as it would against any repo.

```
npm install
npx playwright install chromium   # once
npm start                          # http://localhost:4310
npm test
npm run e2e
```

Repo rules for agents are in [AGENTS.md](AGENTS.md); docs and tickets are indexed in [docs/README.md](docs/README.md).
